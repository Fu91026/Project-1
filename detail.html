Café Brand Website

Responsive web design project for a local café.

Project Overview

This project aims to create a simple, mobile-friendly website for a small café. The goal is to show menu, opening hours and contact information clearly.

Design Process

First, I created wireframes in Figma with a 12-column grid. Then I built the layout using CSS Grid and Flexbox for responsiveness.

Final Outcome

The site works well on both desktop and mobile screens. Navigation stays simple for all users.
